# 用户模型连接

在「设置 → 模型连接 → 配置向导」选择常用供应商预设或自定义兼容地址，然后输入 Key。支持文本、向量（固定 1024 维）、视觉和重排。可以一次选择多种用途。模型发现可用时会列出候选 ID，也可以直接手填供应商提供的模型 ID 或部署 ID。测试通过的连接可以用于聊天选择，或者由你设为该用途的账户默认。探测使用合成样例，可能产生少量费用。

聊天输入区的「聊天模型」可选择已测试的个人文本连接，或使用账户默认。选择保存在当前会话，从下一次发起生成开始生效。切换供应商后，生成所需的会话上下文会按现有聊天规则发送给所选供应商。个人模型故障时，可以在设置检查或重新测试连接，也可以在对话里切换后点击「用当前模型重试」。该动作复用已有问题。

## 部署配置

在 `backend` 目录生成独立的凭据加密密钥：

```powershell
uv run python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

将结果配置到部署环境的 `MODEL_CONNECTIONS_KEY`，API 和 worker 必须使用同一个值。它与登录签名密钥相互独立，使用 Fernet 认证加密。密钥与数据库应分别保管、备份；丢失或直接替换密钥会使已有凭据无法解密，需要重新填写各连接的 API Key。不要将真实值提交到仓库。未配置时，个人连接保存会明确失败，平台连接仍可使用。

请求由**后端服务器**发出。默认仅接受公网 HTTPS 地址，每次建立连接都会检查 DNS 解析结果，并连接到已验证的 IP；禁止自动重定向和环境代理。管理员如需使用 Ollama 或内网网关，可配置精确的协议、主机和端口，例如：

```dotenv
MODEL_ALLOWED_ORIGINS=["http://127.0.0.1:11434","https://models.internal:8443"]
```

放行 origin 适用于其所有 API 路径，不支持通配域名或任意内网。修改策略后需重启 API 和 worker。使用容器部署时，`127.0.0.1` 指向后端容器自身。

升级现有部署时，在 `backend` 使用迁移账户执行 `uv run alembic upgrade head`。`0017_conversation_llm` 在 `study` 保存可空的会话文本连接引用。旧会话继续使用账户默认连接。

## 默认选择与任务

- 会话模型用于本会话的回答、摘要和检索改写。账户默认文本连接还用于学习出题、语义判题和资料分类。
- 新知识库绑定创建时的默认向量连接；入库、检索和学习检索始终使用该绑定。切换默认或恢复平台默认只影响之后创建的库。
- 默认视觉连接只在用户显式勾选上传、选择重新解析或开启拍照判题辅助时调用。资料解析会把图片或 PDF 页图发给配置的供应商，拍照判题还会发送题目与参考答案。视觉解析默认关闭，PDF 默认最多 20 页，可用 `MAX_VLM_PAGES_PER_MATERIAL` 调整。用量分别标记为资料视觉解析和视觉判题。
- 已开始的任务固定连接版本；上传与分类任务将快照持久化，恢复和自动重试继续使用原版本。用户显式重试资料会创建新任务，使用库绑定连接的当前已测试版本。
- 地址、模型或 Key 更改后需要重新测试。已绑定库的连接只能改名或更换 Key，更换地址或模型须新增连接。测试失败期间库的后续模型操作会暂停，已有索引保留。
- 运行中的连接暂时不能删除；被有效知识库引用或仍为账户默认的连接也不能删除。删除提示会列出受影响的库。
- 个人连接报错不会切换到平台服务。平台默认继续使用原有的平台备用规则。用量显示实际模型、平台或个人连接来源及版本，不保存提示词或完整凭据。

聊天可用性按会话文本连接和所选知识库的向量绑定判断。`/health/ready` 检查数据库、迁移、认证和存储。离线 RAG 评测 CLI 使用平台评测配置。

## 排错

| 状态 | 操作 |
| --- | --- |
| 认证失败 | 检查 Key、模型访问权限，替换后重新测试 |
| 余额或限流 | 检查供应商余额与速率限制，稍后重试 |
| 超时 / DNS | 检查后端服务器的网络、服务地址和供应商状态 |
| 协议不兼容 | 检查 Base URL 是否包含正确 API 前缀，LLM 是否支持流式文本 |
| 向量维度错误 | 选择支持 1024 维输出和批量请求的模型 |
| 地址被阻止 | 使用公网 HTTPS，或由管理员精确放行内网 origin |
| 无法解密 | 检查 API 与 worker 的加密密钥是否一致，或重新填写 Key |

## 验证

`backend/tests/integration/test_model_connections.py` 使用隔离 PostgreSQL 测试库及本机兼容 API 测试服务，覆盖连接隔离、加密脱敏、真实流式和批量协议、模型切换、库绑定、任务恢复及索引保护；`test_model_network.py` 验证地址策略。前端测试覆盖草稿保存、测试与默认状态、凭据清空和部署加密密钥缺失的反馈。真实供应商验收需要另行提供测试连接；自动测试不会使用部署环境中的真实 Key。

2026-11-17 本地验收：后端 259 项测试、Ruff、前端 55 项测试与生产构建通过。迁移测试覆盖升级、降级、再次升级及旧 profile 保留；兼容服务验证两套 LLM 的真实问答、摘要、改写、学习与分类调用。浏览器验证 1440px 桌面和 390px 窄屏的草稿保存、测试、默认选择、向量错误恢复、键盘选型及凭据遮罩。真实供应商连接尚未验证。
